# Simple To-Do List App

A small client-side To-Do List application built with plain HTML, CSS, and JavaScript.

## Features

- Create, read, update, and delete tasks
- Persist tasks using `window.localStorage`
- Filter tasks by `All`, `Active`, and `Completed`
- Edit tasks inline
- Clear completed tasks

## Files

- `index.html` - app markup
- `styles.css` - styling
- `app.js` - application logic and state management

## Usage

1. Open `index.html` in a browser.
2. Add tasks using the input field.
3. Toggle tasks complete with the checkbox.
4. Edit tasks by clicking the task text or edit button.
5. Delete tasks with the delete button.
6. Filter tasks using the buttons, and clear completed tasks.

## Notes

- All data is stored locally in the browser.
- No build tools or external libraries are required.
